# Paweo privacy policy

The published privacy policy of the Paweo Android app (formerly Petcare+), served with GitHub Pages at
https://hakansaglamgermany.github.io/paweo-privacy/

The source lives in the (private) app repository as `docs/privacy-policy*.md` (English at `/`, each translation at `/<lang>/`); publish with `python3 docs/privacy-sync.py ~/Projects/paweo-privacy` there.
